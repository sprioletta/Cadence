# Cadence

A modern Linux system backup and restore application built with Rust and GTK4, featuring reliable snapshot-based backups using rsync.

## Project status

**Early development — architecture and initial application shell.**

Cadence is being built from scratch with a focus on reliability, safety, clear separation of concerns, and a responsive desktop experience.

## Planned initial scope

- GTK4 desktop interface
- RSYNC-based snapshot engine
- Snapshot browsing and restore workflows
- Explicit safety checks and clear operation status

See [Architecture](docs/ARCHITECTURE.md) and [Roadmap](docs/ROADMAP.md).

## Platform

Linux desktop. The initial UI stack is Rust with GTK4 and libadwaita.
